# Contributing

Contributions should improve architecture clarity, validation discipline, recovery guidance, or public-safe evidence handling.

Before opening a pull request:

```bash
python3 scripts/check_public_safety.py
python3 scripts/check_markdown_links.py
```

Do not submit live configuration, credentials, exact topology, raw evidence, malware, or runnable attack automation. Use the aliases and status language defined in the sanitization policy.
