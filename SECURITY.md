# Security policy

## Sensitive content

Do not open a public issue containing credentials, tokens, keys, internal topology, raw evidence, or exploitable lab configuration.

Use GitHub private vulnerability reporting for security-sensitive repository findings. If a secret is discovered in history, revoke it first; removing it from the latest commit is not sufficient.

## Scope

This repository contains sanitized documentation and example metadata only. It is not the live deployment source and should never become a backup of operational configuration.
